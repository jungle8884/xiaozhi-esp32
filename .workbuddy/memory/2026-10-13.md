### 修复动作（✅ 已完成并实测通过）
**方案：在项目代码里打补丁（不是改 site-packages）**

`core/providers/tts/edge.py` —— 导入 `edge_tts` 后追加：

```python
_LEGACY_WSS_HOST = "speech.platform.bing.com"
_V2_WSS_URL = (
    "wss://api.msedgeservices.com/tts/cognitiveservices/websocket/v1"
    "?Ocp-Apim-Subscription-Key=" + edge_tts.constants.TRUSTED_CLIENT_TOKEN
)

def _apply_edge_tts_v2_patch():
    try:
        import edge_tts.communicate as _communicate
    except Exception:
        return
    if _LEGACY_WSS_HOST in getattr(_communicate, "WSS_URL", ""):
        _communicate.WSS_URL = _V2_WSS_URL

_apply_edge_tts_v2_patch()
```

原理：`communicate.py:466` 在方法内引用**模块级全局** `WSS_URL`（`from .constants import WSS_URL`），所以替换 `edge_tts.communicate.WSS_URL` 即可生效（只改 `edge_tts.constants.WSS_URL` 无效，因为已被 by-value 导入）。
带自动判断：上游修好后端点不再含旧域名，补丁自动让路，整段可删。

**配套**：`requirements.txt` 的 `edge_tts==7.0.0` → **`edge_tts>=7.2.8`**（避免重装时降级，旧版 Sec-MS-GEC-Version 更旧，v2 端点不保证接受）。
**环境**：conda 环境 `xiaozhi-server` 里 edge-tts 已从 7.0.0 升级到 **7.2.8**（PyPI 最新）。
